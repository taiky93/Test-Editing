# Test-Editing

Projet de test pour expérimenter l'édition de fichiers.

## Contenu

- `README.md` — ce fichier
- `exemple.txt` — un fichier d'exemple à modifier librement

## Utilisation

Modifiez les fichiers, puis enregistrez vos changements :

```bash
git add .
git commit -m "Mon modification"
git push
```
